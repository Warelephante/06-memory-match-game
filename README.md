# Emoji Memory Match

A simple single-player memory game made with HTML, CSS, and JavaScript.

## Play the game

Open `index.html` in a web browser. Select two cards to find a matching emoji
pair. The game counts your moves and time, and the **Restart** button starts a
new shuffled game.

## Project files

- `index.html` contains the game page and its controls.
- `style.css` styles the game and adapts the layout to smaller screens.
- `script.js` creates and shuffles the cards, checks matches, and keeps score.
